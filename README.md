## Cómo actualizar una web

1. Cambia y versiona la web en su repositorio de origen.
2. Copia aquí solo los archivos que se sirven, sin documentación, pruebas ni scripts.
3. Haz commit y push a `main`; GitHub Pages publica en uno o dos minutos.
4. Comprueba la dirección sin iniciar sesión.
